In March 2024, I was afraid of learning React — afraid I'd start something and not finish it, like before.

I did it anyway.

Since then I've shipped a multitenant fitness education platform from scratch, got hired at a US-based software company, automated workflows that replaced 5 FTEs worth of manual work, and built infrastructure across AWS, GCP, and Linux VPS environments. All while still in college.

Now I'm open again — for new pressure, new problems, and new things to build.

## What I'm Building

**UMak-Link** — A centralized lost & found platform for University of Makati (React + Capacitor + FastifyJS + Supabase). Uses Gemini vision to classify item images into structured metadata, then runs PostgreSQL full-text + similarity search to match lost and found items.

**Hope Hub** — Multitenant fitness education platform (React + PostgreSQL + Supabase) serving as a professor's active thesis project. Role-based access for Teachers and Students across Lectures, Quizzes, Physical Fitness Tests, and Workout Zone.
